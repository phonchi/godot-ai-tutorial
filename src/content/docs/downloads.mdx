每個 ZIP 都包含獨立的 `project.godot`、場景、腳本與專案規則。解壓縮後，在 Godot 專案管理員按「匯入」，選擇 `project.godot`，再按 **F6** 執行目前場景或 **F5** 執行專案。

## 如何接續學習

先備份自己的專案，再把下載的階段版解壓縮至另一個目錄。分別開啟兩份專案對照，不要把整包檔案直接覆蓋自己的成果。教材使用 Godot **4.7.2**；其他版本請先在副本開啟，注意節點、屬性與 API 的差異。

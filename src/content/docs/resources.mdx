## Godot 官方資料

- [正體中文前言](https://docs.godotengine.org/zh-tw/4.x/about/introduction.html)：認識引擎與文件架構。
- [Godot 4.7 文件](https://docs.godotengine.org/en/4.7/)：本課程 API 核對依據；中文翻譯未齊時以相符版本英文文件補充。
- [第一個 2D 遊戲](https://docs.godotengine.org/en/4.7/getting_started/first_2d_game/index.html)與[第一個 3D 遊戲](https://docs.godotengine.org/en/4.7/getting_started/first_3d_game/index.html)。
- [命令列操作](https://docs.godotengine.org/en/4.7/tutorials/editor/command_line_tutorial.html)與[網頁匯出](https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_web.html)。
- [官方範例專案](https://github.com/godotengine/godot-demo-projects)。

## AI agent 文件

- [Claude Code 概覽](https://code.claude.com/docs/en/overview)、[專案記憶與規則](https://code.claude.com/docs/en/memory)、[MCP](https://code.claude.com/docs/en/mcp)。
- [Codex CLI](https://developers.openai.com/codex/cli/)、[AGENTS.md](https://developers.openai.com/codex/guides/agents-md/)、[MCP](https://developers.openai.com/codex/mcp/)。

## 學習目標

接下來七章要做一款 2D 遊戲「星星花園」（Star Garden）。完整規格是：**俯視角，用 WASD、方向鍵或手把左搖桿移動，按 Shift、Space 或手把 B 鍵衝刺；分三波收集共 10 顆星星獲勝（3、3、4 顆），被敵人碰到會少一顆心，3 顆心用完就失敗；按 R 或手把 Back 重新開始**。本章只完成「移動與衝刺」：

1. 在「輸入對應」（Input Map）中建立 `move_left`、`move_right`、`move_up`、`move_down`、`dash`、`restart` 六個動作，同時綁定鍵盤與手把。
2. 用 `CharacterBody2D` 建立玩家，`Motion Mode` 設為 `Floating`。
3. 用 `velocity.move_toward()` 做出「慢慢加速、放開後滑行一小段」的移動手感。
4. 做出一個有持續時間與冷卻時間的衝刺，理解「用計時變數表示小狀態」。
5. 用牆壁圍住場地，按 R 重新載入場景。

完成後可以下載 2D 範例的「01 movement」階段對照，見 [下載頁](../../downloads/)。

## 核心概念

### 2D 座標

Godot 2D 的原點在左上角，**X 向右為正，Y 向下為正**。所以「往上走」是 Y 減少。這和數學課的座標方向相反，是新手最常搞反的地方。

### 為什麼用 CharacterBody2D

Godot 有幾種 2D 物理節點：

- `StaticBody2D`：不會動的物體，例如牆壁。
- `RigidBody2D`：由物理引擎推動，例如會被撞飛的箱子。
- `CharacterBody2D`：由**你的程式**決定速度，碰到東西時由引擎處理滑動與停止。最適合玩家角色。
- `Area2D`：不擋路，只偵測誰進出。下一章的星星就會用它。

`CharacterBody2D` 有一個 `Motion Mode` 屬性。預設的 `Grounded` 適合有重力、有地板的橫向卷軸遊戲；俯視角遊戲沒有「地板」的概念，請改成 **`Floating`**，碰撞時的滑動行為會更自然。

### 手感來自「逐步接近目標速度」

最簡單的移動是 `velocity = direction * speed`：按下就全速，放開就立刻停。這很準確，但感覺生硬。改成每個物理影格讓速度**朝目標速度靠近一小步**，就會有加速與滑行：

- 有輸入時，目標速度是 `direction * speed`，每秒最多改變 `acceleration`。
- 沒有輸入時，目標速度是零，每秒最多減少 `friction`。

`Vector2.move_toward(目標, 最大變化量)` 正好做這件事。把變化量乘上 `delta`，速度的變化就和影格率無關。

### 衝刺是一個有時間限制的小狀態

衝刺時，角色朝固定方向高速移動 0.15 秒，期間不理會一般移動；結束後要等 0.75 秒冷卻才能再衝。這種「持續一段時間」的狀態，不一定要用 `Timer` 節點。兩個倒數用的浮點數就夠了：

- `dash_left`：衝刺還剩幾秒，大於 0 代表正在衝刺。
- `cooldown_left`：冷卻還剩幾秒，大於 0 代表還不能衝刺。

每個物理影格把它們減去 `delta`，就能判斷目前在哪個狀態。

## 動手操作

### 步驟 1：建立專案與輸入動作

1. 用專案管理員在 `~/godot-projects/` 建立新專案 `star-garden`，繪圖器選 **Compatibility**（之後要匯出 Web）。在檔案系統面板按右鍵 →「新增資料夾」建立 `scripts/`，之後的腳本都存在這裡，路徑就和下載版、agent 提示詞一致。
2. 開啟「專案 → 專案設定 → 輸入對應」（Project → Project Settings → Input Map）。
3. 在「新增動作」欄位依序新增 `move_left`、`move_right`、`move_up`、`move_down`、`dash`、`restart`。
4. 每個動作按右側「+」綁定按鍵。加入手把按鈕或搖桿時，在對話框的事件清單中展開「Joypad Buttons」或「Joypad Axes」類別，也可以在對話框開啟時直接按手把上的按鍵或推搖桿：

| 動作 | 鍵盤 | 手把 |
| --- | --- | --- |
| `move_left` | A、左方向鍵 | 十字鍵左、左搖桿 X 軸負方向 |
| `move_right` | D、右方向鍵 | 十字鍵右、左搖桿 X 軸正方向 |
| `move_up` | W、上方向鍵 | 十字鍵上、左搖桿 Y 軸負方向 |
| `move_down` | S、下方向鍵 | 十字鍵下、左搖桿 Y 軸正方向 |
| `dash` | Shift、Space | B（Xbox 配置）、X |
| `restart` | R | Back（Select） |

5. 每個動作右邊有 `Deadzone`（死區），預設 `0.5`。搖桿動作建議改成 `0.25`，輕推搖桿就能慢慢走。

Godot 內建的 `ui_left` 等動作是給選單介面用的，沒有 WASD，所以我們自己建立遊戲用的動作。輸入對應會存進 `project.godot`，建議在編輯器中手動完成，比讓 agent 直接改設定檔安全。沒有手把也沒關係，鍵盤綁定就能完成整個課程。

### 步驟 2：建立玩家場景

1. 新增場景，根節點選 `CharacterBody2D`，改名為 `Player`。
2. 在檢查器中把 `Motion Mode` 設為 `Floating`。
3. 加入子節點 `CollisionShape2D`，`Shape` 選「新增 CircleShape2D」，半徑設為 `20`。
4. 加入子節點 `Polygon2D` 當外觀，在 `Polygon` 陣列輸入一個以原點為中心的形狀（例如八邊形），或改用 `Sprite2D` 搭配一張圓形圖片。下載版的玩家是在 `_draw()` 中用程式畫的奶油色圓球，第 8 章會介紹這種畫法。
5. 在節點面板的「群組」分頁，把 `Player` 加入 `player` 群組，之後的星星與敵人會用它辨識玩家。
6. 存成 `player.tscn`。

### 步驟 3：附加移動與衝刺腳本

對 `Player` 附加新腳本，路徑設為 `res://scripts/player.gd`：

```gdscript
# 示範概念：有加速、摩擦與衝刺的俯視角移動
extends CharacterBody2D

signal dashed

@export var speed: float = 270.0
@export var acceleration: float = 1800.0
@export var friction: float = 2300.0
@export var dash_speed: float = 800.0
@export var dash_time: float = 0.15
@export var dash_cooldown: float = 0.75

var facing := Vector2.RIGHT
var dash_left: float = 0.0
var cooldown_left: float = 0.0
var dash_direction := Vector2.ZERO

func _physics_process(delta: float) -> void:
	cooldown_left = maxf(0.0, cooldown_left - delta)
	var direction := Input.get_vector("move_left", "move_right", "move_up", "move_down")
	if direction != Vector2.ZERO:
		facing = direction.normalized()
	if Input.is_action_just_pressed("dash"):
		try_dash()
	if dash_left > 0.0:
		dash_left -= delta
		velocity = dash_direction * dash_speed
	else:
		apply_movement(direction, delta)
	move_and_slide()

func apply_movement(direction: Vector2, delta: float) -> void:
	velocity = velocity.limit_length(speed)
	if direction == Vector2.ZERO:
		velocity = velocity.move_toward(Vector2.ZERO, friction * delta)
	else:
		velocity = velocity.move_toward(direction * speed, acceleration * delta)

func try_dash() -> bool:
	if dash_left > 0.0 or cooldown_left > 0.0:
		return false
	dash_direction = facing
	dash_left = dash_time
	cooldown_left = dash_cooldown
	dashed.emit()
	return true
```

按 F6 單獨執行玩家場景。按住方向鍵時角色會在約 0.15 秒內加速到最高速，放開後滑行一小段才停；按 Shift 會往目前面向的方向衝出約 120 像素。此時還沒有牆，角色可能跑出畫面。

### 步驟 4：建立主場景與牆壁

1. 新增場景，根節點 `Node2D`，命名 `Main`，存成 `main.tscn`。
2. 在「專案設定 → 顯示 → 視窗」把視窗大小設為 `960 × 600`，與下載版相同。
3. 把 `player.tscn` 從檔案系統拖進場景，放在畫面中央附近 `(480, 324)`。
4. 新增子節點 `StaticBody2D` 命名為 `Walls`，在它底下加四個 `CollisionShape2D`，形狀都用 `RectangleShape2D`，分別擺在畫面的上、下、左、右邊緣。
5. 為了看得到牆，可以在 `Walls` 底下加四個 `ColorRect` 對齊碰撞形狀；或在執行時開啟「除錯 → 顯示碰撞形狀」（Debug → Visible Collision Shapes）。
6. 在「專案設定 → 應用程式 → 執行」把 `main.tscn` 設為主場景，按 F5 執行。

### 步驟 5：按 R 重新開始

對 `Main` 附加腳本 `res://scripts/main.gd`：

```gdscript
# 示範概念：按 R 重新載入目前場景
extends Node2D

func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed("restart"):
		get_tree().reload_current_scene()
```

把重開放在主場景而不是玩家身上，是因為「重開遊戲」是整局的事情。之後玩家失敗時，重開功能仍然要能用。

## 程式碼解說

- `@export var speed: float = 270.0`：`@export` 讓變數出現在檢查器中，不改程式就能調整。速度單位是「像素／秒」，加速度與摩擦是「像素／秒²」。
- `Input.get_vector(...)`：依序傳入負 X、正 X、負 Y、正 Y 四個動作，回傳一個長度不超過 1 的 `Vector2`，所以斜向不會比直線快。用搖桿時，輕推會得到較短的向量，角色就走得比較慢。
- `facing = direction.normalized()`：記住最後一次有輸入的方向。衝刺時若沒有按方向鍵，就沿著這個方向衝。
- `velocity.move_toward(目標, 量)`：讓速度朝目標前進，但每次最多改變「量」。乘上 `delta` 後，`acceleration` 的意思就是「每秒最多改變多少速度」。
- `velocity.limit_length(speed)`：衝刺結束後，速度可能還是 800。先把長度限制回一般速度，角色就不會在衝刺後滑出一大段。
- `try_dash()` 回傳 `bool`：成功衝刺回傳 `true`，冷卻中回傳 `false`。呼叫的一方和自動測試都能確認結果。
- `signal dashed`：衝刺開始時發出。玩家不需要知道誰在乎這件事，第 11 章會讓主場景接收它，播放音效與粒子。
- `move_and_slide()`：依照 `velocity` 移動，遇到碰撞時沿著表面滑動。它內部已經使用物理影格的時間，這裡**不需要**再乘 `delta`。
- `event.is_action_pressed("restart")`：只在按下那一刻觸發一次，不會因為按住而連續重開。

## 練習

1. 把 `acceleration` 和 `friction` 改成極端值（例如 `200` 與 `20000`），體驗「溜冰」與「急停」兩種手感，再找出你喜歡的數字。
2. 讓角色的外觀朝向移動方向旋轉（提示：`rotation = facing.angle()`）。
3. 加入一個 `Camera2D` 作為玩家的子節點，把場地放大成兩倍，觀察鏡頭跟隨的效果；再設定鏡頭的 `Limit` 屬性，讓鏡頭不會照到場地外。

## 常見錯誤與限制

- **按鍵沒反應**：動作名稱拼錯（`move_lfet`）時，Godot 會在輸出面板出現找不到該動作的錯誤。也要確認遊戲視窗有取得鍵盤焦點。
- **上下顛倒**：記得 2D 的 Y 軸向下為正。
- **衝刺後滑出很遠**：少了 `limit_length(speed)`，速度從 800 開始慢慢被摩擦減少。
- **衝刺按住會連續觸發**：用了 `is_action_pressed`。要偵測「按下那一刻」請用 `is_action_just_pressed`。
- **搖桿放開角色還在慢慢飄**：搖桿回中時仍有一點讀值，把該動作的 `Deadzone` 調高一點。
- **角色穿牆**：牆的 `CollisionShape2D` 沒有設定形狀，或牆用了 `Area2D` 而不是 `StaticBody2D`。
- **在 `_process` 中呼叫 `move_and_slide()`**：可以執行，但物理行為會隨影格率變動，請放在 `_physics_process`。
- **WSLg 視窗中按鍵偶爾失靈**：多半是焦點問題，點一下遊戲視窗再試。

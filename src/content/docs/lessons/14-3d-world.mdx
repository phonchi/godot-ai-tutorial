## 學習目標

3D 遊戲叫做「浮空島」（Floating Isles）。完整規格是：**第三人稱跟隨攝影機；WASD、方向鍵或左搖桿依攝影機方向移動，空白鍵或手把 A 跳躍；在島嶼與移動平台間收集 5 顆發光寶珠，打開石拱門後走進去獲勝；掉到高度 −10 以下或碰到滾動的刺球，會回到最近的重生點；按 R 或手把 Back 重新開始**。本章先完成世界：

1. 理解 Godot 3D 的座標軸方向與單位。
2. 用 `WorldEnvironment` 設定程序化天空、環境光、色調映射、霧與光暈。
3. 加入會投射陰影的 `DirectionalLight3D`，並知道陰影設定對效能的影響。
4. 用 `MeshInstance3D` 搭配 `StaticBody3D` 與 `CollisionShape3D`，疊出「草地＋泥土」的浮空島。
5. 用構圖原則安排畫面：地平線、前中後三層景深、霧色與天空一致。

本章對應 3D 範例的「01 world」階段，見 [下載頁](../../downloads/)。這個階段的角色還不能動，只是站在起點讓你看清楚世界。

## 核心概念

### 3D 座標

Godot 3D 使用右手座標系：

- **X**：向右為正。
- **Y**：**向上**為正（注意：和 2D 的向下相反）。
- **Z**：朝向你（螢幕外）為正，所以「往前」通常是 **-Z**。

單位慣例是 **1 單位 = 1 公尺**。重力、跳躍高度都用這個尺度，所以角色高約 1.4、島嶼寬 4 到 12 比較自然。浮空島的路線就是沿著 -Z 一路往前延伸到拱門。

### 外觀和碰撞是分開的

和 2D 一樣，3D 中「看得到」和「碰得到」是兩件事：

- `MeshInstance3D` 負責外觀，`Mesh` 屬性可以選 `BoxMesh`、`SphereMesh`、`CylinderMesh`、`CapsuleMesh` 等基本形狀。
- `StaticBody3D` 加上 `CollisionShape3D` 負責碰撞，形狀可選 `BoxShape3D` 等。

一座浮空島其實是三個方塊疊起來：最上面一片薄薄的草地、下面一塊略小的泥土、最底下再一塊更小更暗的泥土，看起來就像從地面被挖起來的一塊。碰撞只需要一個和草地一樣大的盒子，下面的泥土純粹是裝飾。

### 環境決定整體氣氛

`WorldEnvironment` 裡的 `Environment` 資源決定「整個世界看起來怎樣」：

| 設定 | 作用 |
| --- | --- |
| `Sky` + `ProceduralSkyMaterial` | 不用圖片，用頂部、地平線、地面三種顏色漸層做出天空 |
| 環境光（Ambient） | 照亮陰影面，避免背光處全黑 |
| 色調映射（Tonemap） | 把亮度壓到螢幕可顯示的範圍；`ACES` 對比較強，`exposure` 調整整體亮度 |
| 調整（Adjustments） | 微調飽和度、對比 |
| 霧（Fog） | 讓遠處逐漸融入霧色，製造距離感 |
| 光暈（Glow） | 讓很亮或自發光的物體泛出光暈，下一章的寶珠會用到 |

本課程使用 **Compatibility** 繪圖器，以便匯出 Web。依 Godot 4.7 官方的繪圖器比較表，Compatibility 支援光暈、深度與高度霧、色調映射；**不支援**體積霧、螢幕空間反射（SSR）、SDFGI 等進階效果。所以畫面要靠顏色、光線方向和構圖取勝。

### 構圖：讓截圖一眼就有空間感

- **地平線放在畫面上方約三分之一**：攝影機稍微往下看，地面與天空都看得到。
- **前、中、後三層**：近處是起點島，中間是要跳過去的路線，遠處是只用來看的小島，越遠越淡。
- **霧色等於地平線顏色**：遠處的島會自然融進天空，而不是變成一塊灰色。
- **低角度暖色太陽**：陰影拉長，立體感更明顯。

## 動手操作

### 步驟 1：建立 3D 專案與輸入

在 `~/godot-projects/` 建立新專案 `floating-isles`，繪圖器選 **Compatibility**，並在檔案系統面板建立 `scripts/` 資料夾存放腳本。在輸入對應中建立：

| 動作 | 鍵盤 | 手把 |
| --- | --- | --- |
| `move_left`／`move_right`／`move_up`／`move_down` | WASD、方向鍵 | 左搖桿、十字鍵 |
| `jump` | 空白鍵 | A（下方按鈕） |
| `restart` | R | Back |
| `start` | Enter | Start |

`start` 要到第 17 章加入標題畫面時才會用到，先建好比較方便。手把的搖桿在「+」對話框的事件清單中展開「Joypad Axes」類別，左右是 `Left Stick X` 的負向與正向，上下是 `Left Stick Y`。

### 步驟 2：熟悉 3D 視窗操作

新增場景，根節點選 `Node3D`，命名 `Main`。在 3D 視窗中：

- 按住滑鼠**右鍵**拖曳旋轉視角，同時按 WASD 可以飛行移動。
- 滑鼠**中鍵**拖曳旋轉視角，按住 `Shift` 再用中鍵拖曳則是平移；滾輪縮放；選取物件後按 `F` 聚焦到它。
- 工具列的移動（W）、旋轉（E）、縮放（R）模式，配合紅 X、綠 Y、藍 Z 箭頭操作。

### 步驟 3：天空與環境

1. 在 `Main` 底下加入 `WorldEnvironment`，`Environment` 欄位選「新增 Environment」。
2. `Background → Mode` 選 `Sky`，`Sky` 欄位新增 `Sky`，再在 `Sky Material` 新增 `ProceduralSkyMaterial`。
3. 天空頂部設為藍色（例如 `#4f8fbf`），地平線與地面地平線設為暖杏色（例如 `#f2c79a`），地面底部設為淺藍。
4. `Ambient Light → Source` 選 `Color`，顏色選偏藍的灰（例如 `#8fa3c0`），`Energy` 約 `0.6`。
5. `Tonemap → Mode` 選 `ACES`，`Exposure` 約 `0.85`；`Adjustments` 勾選啟用，`Saturation` 約 `1.2`。
6. 勾選 `Fog`，`Light Color` 設成和地平線相同的杏色，`Density` 約 `0.0045`，`Sky Affect` 約 `0.25`（讓天空只淡淡受霧影響）。
7. 勾選 `Glow`，`Intensity` 約 `0.45`。

### 步驟 4：太陽與陰影

1. 加入 `DirectionalLight3D`，命名 `Sun`，旋轉約 `(-32, -40, 0)` 度，顏色選暖白（例如 `#ffe2b8`）。
2. 勾選 `Shadow → Enabled`。
3. 在 `Directional Shadow` 中把 `Mode` 改成 `PSSM 2 Splits`，`Max Distance` 設 `45`。

陰影是 3D 最吃效能的項目之一。分割數越少、最大距離越短，Web 上越順；45 公尺已經涵蓋攝影機看得到的範圍。

### 步驟 5：第一座浮空島

1. 在 `Main` 底下加 `StaticBody3D`，命名 `StartIsland`，位置 `(0, 0, 8)`。
2. 底下加 `MeshInstance3D`，`Mesh` 新增 `BoxMesh`，大小 `(10, 0.35, 9)`，位置 `(0, -0.175, 0)`，材質選綠色草地。
3. 再加一個 `MeshInstance3D`，`BoxMesh` 大小 `(9.6, 1.6, 8.6)`，位置 `(0, -1.15, 0)`，材質選土棕色。
4. 再加一個更小的 `BoxMesh` `(5.5, 1.4, 5)`，位置 `(0, -2.6, 0)`，材質選更暗的棕色。
5. 加入 `CollisionShape3D`，`BoxShape3D` 大小 `(10, 1, 9)`，位置 `(0, -0.5, 0)`。

這樣島的**上表面剛好在節點位置的高度**（這裡是 Y = 0），之後擺東西只要記得「島頂高度」就好。選取整座島按 `Ctrl+D` 複製，就能做出路線上的其他島；記得材質與網格是共用資源，要獨立修改時按右鍵選「唯一化」（Make Unique）。

### 步驟 6：路線、遠景與裝飾

1. 複製出 4 到 5 座島，沿 -Z 方向排列，每座比前一座高 0.5 到 0.8，間距 1 到 2.5 公尺，確保之後跳得過去。
2. 再複製幾座島放到很遠的地方（例如 X ±20、Z −40 以外），刪掉它們的 `CollisionShape3D`，當成只看不碰的遠景。
3. 樹：`CylinderMesh` 當樹幹，上面疊兩顆低面數的 `SphereMesh`（`Radial Segments` 7、`Rings` 4）當樹冠。
4. 雲：在島嶼下方約 Y = −6 放幾顆壓扁的白色 `SphereMesh`，例如縮放 `(9, 1.8, 5)`，並把 `Cast Shadow` 關掉。
5. 加入 `Camera3D`，放在起點島後上方約 `(0, 4.4, 17)`，稍微往下看，讓地平線落在畫面上方三分之一。按 F6 執行看看。

## 程式碼解說：用函式重複搭島

下載版用程式建立整個世界。重複的形狀交給小函式處理：

```gdscript
# 示範概念：一座浮空島 = 草地 + 兩層泥土 + 一個碰撞盒
func make_island(top: Vector3, size: Vector2, solid: bool) -> void:
	var island: Node3D = StaticBody3D.new() if solid else Node3D.new()
	island.position = top
	island.add_child(make_box(Vector3(size.x, 0.35, size.y), GRASS, Vector3(0, -0.175, 0)))
	island.add_child(make_box(Vector3(size.x - 0.4, 1.6, size.y - 0.4), EARTH, Vector3(0, -1.15, 0)))
	if solid:
		island.add_child(make_collider(Vector3(size.x, 1.0, size.y), Vector3(0, -0.5, 0)))
	add_child(island)
```

- `top` 是島頂中心，`size` 是草地的 X 與 Z 尺寸（用 `Vector2` 表示平面大小）。
- `solid` 為 `false` 的遠景島只用 `Node3D`，沒有碰撞，省下物理運算。
- **節點位置是形狀的中心**：草地厚 0.35，中心要往下 0.175，上表面才會剛好在 `top`。
- `make_box()` 另外用一個 `material()` 函式**快取材質**：同一種顏色只建立一個 `StandardMaterial3D`，所有同色方塊共用。物件多的時候，共用材質能減少繪圖狀態切換。
- 世界資料寫成常數陣列（`ISLANDS`、`TREES`、`ROCKS`），想改關卡只要改數字，不用動流程。

## 練習

1. 把 `ProceduralSkyMaterial` 換成夜晚配色，再把環境光調暗、霧調成深藍，觀察同一座島的氣氛差異。
2. 比較 `Tonemap` 的 `Linear`、`Filmic`、`ACES` 三種模式，截圖並說明哪一種讓草地顏色最飽滿。
3. 把太陽陰影的 `Max Distance` 從 45 改成 15 和 100，觀察近處陰影的清晰度與遠處陰影是否消失。

## 常見錯誤與限制

- **畫面一片灰白、看不到天空**：霧太濃，或 `Sky Affect` 太高，天空被霧蓋掉。先把 `Density` 調低。
- **整體過亮、顏色像褪色**：環境光太強、曝光太高，或用了太淺的材質色。依序調低 `Ambient Energy`、`Exposure`，再加深材質顏色。
- **物體一半埋在島裡**：忘了節點位置是中心點。高度為 h 的物件，中心要放在 h / 2。
- **只有外觀沒有碰撞**：`MeshInstance3D` 單獨存在時不會擋住任何東西。
- **改一座島，其他島也變了**：共用資源，使用「唯一化」。
- **Compatibility 的視覺限制**：體積霧、SSR、SDFGI 等效果只在 Forward+ 中可用。為了 Web 匯出，本課程用構圖、顏色和光暈補足。

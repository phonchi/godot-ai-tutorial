## 學習目標

本章讓浮空島上的探險者動起來：

1. 用 `CharacterBody3D` 做出有重力、能跳躍的角色，水平速度用加速與減速逼近目標。
2. 把輸入方向換算成**相對於攝影機**的方向，按「上」永遠是往畫面深處走。
3. 用 **coyote time** 與 **jump buffer** 讓跳躍更寬容：剛走出邊緣、或落地前一瞬間按跳躍都算數。
4. 用 `Tween` 讓角色在起跳與落地時壓扁、拉長，但不改變碰撞形狀。
5. 寫一個平滑跟隨、稍微往前看的攝影機；掉出島嶼時回到起點。

本章對應 3D 範例的「02 controller」階段。

## 核心概念

### 3D 角色的速度分成兩部分

`velocity` 是 `Vector3`，可以拆成兩部分處理：

- **水平（X、Z）**：由輸入決定。用 `move_toward()` 每格往目標速度靠近，按著方向鍵時用 `acceleration`，放開時用 `deceleration`。
- **垂直（Y）**：由重力與跳躍決定。在空中每格減去 `gravity * delta`，起跳時直接設成 `jump_velocity`。

<LessonDiagram kind="coordinates" />

以預設值 `jump_velocity = 8`、`gravity = 22` 計算，最高可跳約 1.45 公尺，同高度可跳過約 4 公尺遠。關卡中島與島的高度差都在 0.8 公尺以內，就是依這個數字設計的。

### 依攝影機方向移動

輸入給的是平面上的 `Vector2`（例如按 W 得到 `(0, -1)`）。要變成 3D 世界中的方向，可以借用攝影機的方向：

- 攝影機的「前方」是 `-camera.global_basis.z`，「右方」是 `camera.global_basis.x`。
- 攝影機略微往下看，所以前方向量帶有一點 Y。把 **Y 設成 0 再正規化**，就得到貼著地面的前方與右方。
- 最後方向 = 右方 × 輸入 X − 前方 × 輸入 Y。

這樣即使之後讓攝影機旋轉，「按上就往畫面深處走」仍然成立。

### 寬容的跳躍：coyote time 與 jump buffer

| 名稱 | 情境 | 做法 |
| --- | --- | --- |
| coyote time | 剛走出平台邊緣才按跳 | 離地後 0.1 秒內仍允許起跳 |
| jump buffer | 還沒落地就先按跳 | 記住這次按鍵 0.12 秒，落地時自動起跳 |

兩者都只是一個會倒數的計時器，跳躍條件變成「`buffer_left > 0` 而且 `coyote_left > 0`」。起跳後立刻把兩個計時器歸零，避免空中連跳。

### 為什麼攝影機不當玩家的子節點

如果 `Camera3D` 是玩家的子節點，角色轉身時攝影機會跟著繞圈，畫面晃動。讓攝影機獨立存在，每個物理影格以固定偏移追上玩家，畫面穩定，也能做出平滑延遲。

## 動手操作

### 步驟 1：玩家場景

1. 新增場景，根節點 `CharacterBody3D`，命名 `Player`。
2. 加入 `CollisionShape3D`，形狀選 `CapsuleShape3D`，半徑 `0.4`、高度 `1.4`。
3. 加入一個 `Node3D`，命名 `Visual`，所有外觀都放在它底下：
   - `MeshInstance3D`：`CapsuleMesh`，半徑 0.4、高度 1.4，奶油色材質。
   - 一個薄薄的 `TorusMesh` 當圍巾、一個小 `BoxMesh` 當背包，薄荷綠色。
   - 兩顆白色小 `SphereMesh` 當眼睛，放在 -Z 那一面（角色的「臉」朝 -Z）。
4. 存成 `player.tscn`。

把外觀集中在 `Visual` 底下，之後轉身與壓扁都只改 `Visual`，碰撞膠囊保持不變。

### 步驟 2：移動、重力與跳躍

對 `Player` 附加 `res://scripts/player.gd`：

```gdscript
# 示範概念：依攝影機方向移動＋寬容跳躍
extends CharacterBody3D

@export var speed := 6.0
@export var acceleration := 30.0
@export var deceleration := 40.0
@export var jump_velocity := 8.0
@export var gravity := 22.0
@export var coyote_time := 0.10
@export var jump_buffer := 0.12

var camera: Camera3D
var coyote_left := 0.0
var buffer_left := 0.0

func _physics_process(delta: float) -> void:
	if is_on_floor():
		coyote_left = coyote_time
	else:
		coyote_left -= delta
		velocity.y -= gravity * delta
	buffer_left -= delta
	if Input.is_action_just_pressed("jump"):
		buffer_left = jump_buffer
	if buffer_left > 0.0 and coyote_left > 0.0:
		velocity.y = jump_velocity
		coyote_left = 0.0
		buffer_left = 0.0
	var input := Input.get_vector("move_left", "move_right", "move_up", "move_down")
	var forward := -camera.global_basis.z
	var right := camera.global_basis.x
	forward.y = 0.0
	right.y = 0.0
	var direction := right.normalized() * input.x - forward.normalized() * input.y
	var rate := acceleration if direction != Vector3.ZERO else deceleration
	var flat := Vector2(velocity.x, velocity.z).move_toward(Vector2(direction.x, direction.z) * speed, rate * delta)
	velocity.x = flat.x
	velocity.z = flat.y
	move_and_slide()
```

### 步驟 3：轉身與壓扁

在同一個腳本加入：

```gdscript
@onready var visual: Node3D = $Visual

func squash(amount: Vector3) -> void:
	visual.scale = amount
	var tween := create_tween()
	tween.tween_property(visual, "scale", Vector3.ONE, 0.22).set_trans(Tween.TRANS_BACK).set_ease(Tween.EASE_OUT)
```

起跳時呼叫 `squash(Vector3(0.8, 1.25, 0.8))`（拉長）；用一個 `was_on_floor` 變數記住上一格是否在地上，「這格在地上、上一格不在」就是落地，呼叫 `squash(Vector3(1.25, 0.75, 1.25))`（壓扁）。移動時用 `lerp_angle()` 讓 `visual.rotation.y` 慢慢轉向 `atan2(-direction.x, -direction.z)`。

### 步驟 4：放進主場景

開啟上一章的 `main.tscn`，把 `player.tscn` 拖進來，放在起點島上方，例如 `(0, 0.75, 9)`（膠囊高 1.4，中心比島頂高 0.7）。

### 步驟 5：平滑跟隨攝影機

把上一章的 `Camera3D` 留在 `Main` 底下，在 `main.gd` 中：

```gdscript
const CAMERA_OFFSET := Vector3(0, 3.6, 8.0)
const LOOK_AHEAD := Vector3(0, 1.2, -4.0)

@onready var player: CharacterBody3D = $Player
@onready var camera: Camera3D = $Camera3D

func _ready() -> void:
	player.camera = camera

func _physics_process(delta: float) -> void:
	var weight := 1.0 - exp(-8.0 * delta)
	camera.global_position = camera.global_position.lerp(player.global_position + CAMERA_OFFSET, weight)
	camera.look_at(player.global_position + LOOK_AHEAD)
```

`LOOK_AHEAD` 讓攝影機看向玩家**前方**一點，你會看到更多即將跳過去的路線。

### 步驟 6：掉出島嶼就回到起點

在 `main.gd` 的 `_physics_process` 加上：當 `player.global_position.y < -10`，把玩家放回起點、`velocity` 歸零，並把攝影機直接放到目標位置（不要讓它從深淵慢慢追上來）。

## 程式碼解說

- `move_toward(target, rate * delta)`：每格最多改變 `rate * delta`。加速 30 代表約 0.2 秒到達最高速；減速 40 讓放開時停得更俐落。
- `1.0 - exp(-8.0 * delta)`：平滑跟隨的權重。直接用固定的 `lerp(…, 0.1)` 會讓 30 FPS 和 60 FPS 的追趕速度不同；用指數形式，不論影格率，約 0.29 秒都能追上 90%。
- `look_at()` 的目標不能和攝影機位置重合，否則會出錯。偏移量 `(0, 3.6, 8)` 確保兩者永遠有距離。
- coyote time 與 jump buffer 都不需要 `Timer` 節點，用 `float` 倒數就夠了，邏輯也全部集中在 `_physics_process`。
- 壓扁只改 `Visual` 的 `scale`。如果直接縮放 `CharacterBody3D`，碰撞膠囊也會變形，可能讓角色卡進地板。

## 練習

1. 把 `LOOK_AHEAD` 的 Z 改成 `-8`，再改成 `0`，比較哪一種更容易判斷跳躍距離。
2. 加入 Q／E 讓攝影機繞玩家旋轉 90 度（旋轉 `CAMERA_OFFSET`），確認「依攝影機方向移動」仍然正確。
3. 把 coyote time 設成 0，再試著從邊緣起跳，體會這 0.1 秒的差別。

## 常見錯誤與限制

- **按上卻往下走**：忘了輸入的 Y 是「上為負」，方向要用 `- forward * input.y`。
- **斜著看時移動速度變慢**：前方向量的 Y 沒有歸零就正規化，部分速度被分到垂直方向。
- **空中可以一直跳**：起跳後沒有把 `coyote_left` 與 `buffer_left` 歸零。
- **角色卡進地板或浮在空中**：縮放了整個 `CharacterBody3D`，或碰撞膠囊與外觀高度不一致。
- **攝影機抖動**：攝影機在 `_process`、角色在 `_physics_process` 更新，兩者頻率不同。把跟隨放在 `_physics_process`。
- **`look_at` 錯誤**：目標點與攝影機位置相同，或攝影機還沒加入場景樹就呼叫。

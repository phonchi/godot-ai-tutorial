## 學習目標

1. 建立一個敵人場景，用 `enum` 區分兩種行為：會追玩家的**追蹤刺球**（chaser）與直線飛行、碰邊反彈的**反彈菱形**（bouncer）。
2. 用 `direction_to()` 算出朝向玩家的方向，讓追蹤刺球每個影格往玩家靠近。
3. 讓新出現的敵人先閃爍 0.5 秒才生效，玩家有時間反應。
4. 用 `Timer` 每 6 秒增加一隻追蹤刺球，最多 5 隻敵人。
5. 玩家有 3 條命；被碰到少一條並無敵 1 秒，命用完判定失敗。
6. 理解「訊號只在進入時觸發一次」，持續接觸要在 `_physics_process` 中每格檢查。
7. 在專案還小時完成第一次 Web 匯出，在瀏覽器中執行。

本章對應 2D 範例的「03 hazards」階段，見 [下載頁](../../downloads/)。

## 核心概念

### 用 enum 讓一個場景有兩種行為

兩種敵人的碰撞方式、受傷規則都一樣，差別只在怎麼移動與長什麼樣子。與其做兩個幾乎相同的場景，不如在同一個腳本中用列舉（`enum`）記住「我是哪一種」：

```gdscript
enum Kind { CHASER, BOUNCER }
@export var kind: Kind = Kind.CHASER
```

加上 `@export` 後，檢查器會出現下拉選單，每個實例可以各自選擇。

### 朝玩家前進：direction_to

`a.direction_to(b)` 回傳從 `a` 指向 `b`、長度為 1 的向量。乘上速度與 `delta`，就是這個影格要走的位移：

```gdscript
position += position.direction_to(target.global_position) * speed * delta
```

每個影格重新計算方向，所以玩家怎麼跑，刺球就怎麼轉彎追。只要追蹤速度（每秒 120 像素）比玩家慢，玩家就有機會甩開，衝刺則是緊急脫身的工具。

### 訊號只在「進入」時觸發一次

`body_entered` 只在玩家**進入**區域的那一刻發出。如果玩家一直貼著敵人，就不會再收到訊號。有兩種情況會因此出錯：

- 玩家在無敵期間碰到敵人，無敵結束後仍然重疊，卻不會再受傷。
- 敵人剛出現時還在閃爍、不算數，玩家正好站在那裡，生效後也不會觸發。

所以下載版**不用訊號判斷受傷**，而是在主場景的 `_physics_process` 中，每個物理影格問每隻敵人「你現在有沒有和玩家重疊？」（`overlaps_body()`）。星星適合用訊號，因為收集只需要發生一次；持續性的傷害則適合每格檢查。

### 受傷規則由誰負責

- **敵人**只負責移動與外觀，另外提供 `is_active()`，回答「我生效了沒」。
- **玩家**記錄自己還剩多少無敵時間（`invulnerable`）。
- **主場景**決定規則：檢查重疊、扣命、給無敵時間、判斷失敗。

### 為什麼這麼早就做 Web 匯出

Web 平台有一些桌面沒有的限制：只支援 Compatibility 繪圖器、音效要等使用者互動後才能播放、有些功能需要特殊的伺服器標頭。專案越大，越難找出是哪一個改動在 Web 上出問題。**趁現在只有幾個場景時先匯出一次**，之後每完成一個階段就再測一次。完整說明在 [第 13 章](../13-web-export/)。

## 動手操作

### 步驟 1：敵人場景

1. 新增場景，根節點 `Area2D`，命名 `Enemy`。
2. 加入 `CollisionShape2D`（`CircleShape2D`，半徑 `16`）。`Layer` 全部取消勾選，`Mask` 只勾第 1 層。
3. 附加腳本 `res://scripts/enemy.gd`，場景存成 `enemy.tscn`：

```gdscript
# 示範概念：兩種行為的敵人，出現後先閃爍 0.5 秒
extends Area2D

enum Kind { CHASER, BOUNCER }

@export var kind: Kind = Kind.CHASER
@export var speed: float = 120.0
var drift := Vector2(150, 90)
var target: Node2D
var arena := Rect2(48, 96, 864, 456)
var warmup: float = 0.5

func is_active() -> bool:
	return warmup <= 0.0

func _physics_process(delta: float) -> void:
	if warmup > 0.0:
		warmup -= delta
	elif kind == Kind.CHASER:
		chase(delta)
	else:
		bounce(delta)
	queue_redraw()

func chase(delta: float) -> void:
	if is_instance_valid(target):
		position += position.direction_to(target.global_position) * speed * delta

func bounce(delta: float) -> void:
	position += drift * delta
	if position.x < arena.position.x or position.x > arena.end.x:
		drift.x = -drift.x
	if position.y < arena.position.y or position.y > arena.end.y:
		drift.y = -drift.y
	position = position.clamp(arena.position, arena.end)

func _draw() -> void:
	var color := Color("e0673f") if kind == Kind.CHASER else Color("e85d8a")
	if not is_active():
		draw_arc(Vector2.ZERO, 26.0, 0.0, TAU, 32, Color(color, 0.6), 3.0)
	else:
		draw_circle(Vector2.ZERO, 18.0, color)
```

`arena` 是可活動範圍，請依你的場地大小調整。外觀先用圓形，下載版的刺球與菱形是在 `_draw()` 中用多邊形畫的，可以在本章最後的原始碼中參考。

### 步驟 2：玩家的無敵時間

在 `player.gd` 加入一個倒數變數，並在 `_physics_process` 開頭減少它：

```gdscript
# 示範概念：玩家記錄自己的無敵時間（加在 player.gd 中）
var invulnerable: float = 0.0

func _physics_process(delta: float) -> void:
	invulnerable = maxf(0.0, invulnerable - delta)
	# 無敵期間閃爍：每 1/12 秒切換一次透明度
	modulate.a = 0.35 if invulnerable > 0.0 and int(invulnerable * 12.0) % 2 == 0 else 1.0
	# ……原本的移動與衝刺程式……
```

順手在 `try_dash()` 裡加上 `invulnerable = maxf(invulnerable, dash_time)`，衝刺期間就能穿過敵人。這讓衝刺不只是「走得快」，還是脫困的方法。

### 步驟 3：放置敵人與生成計時器

1. 打開 `main.tscn`，拖入 3 個 `enemy.tscn`：一個 `kind` 設為 `CHASER`，兩個設為 `BOUNCER`，各放在場地角落，遠離玩家出生點。
2. 新增 `Timer` 節點，命名 `SpawnTimer`，`Wait Time` 設 `6`，勾選 `Autostart`。
3. 選取 `SpawnTimer`，在節點面板把 `timeout` 訊號連接到 `Main` 的 `spawn_hazard` 函式（下一步建立）。

### 步驟 4：主場景的受傷與生成規則

在 `main.gd` 加入：

```gdscript
# 示範概念：每格檢查重疊、扣命、定時生成（加在 main.gd 中）
const MAX_LIVES: int = 3
const MAX_ENEMIES: int = 5
const ENEMY_SCENE := preload("res://enemy.tscn")

var lives: int = MAX_LIVES
var enemies: Array[Area2D] = []
var won: bool = false

func _ready() -> void:
	# ……原本連接星星的程式……
	for child in get_children():
		if child.is_in_group("enemies"):
			child.target = player
			enemies.append(child)

func _physics_process(_delta: float) -> void:
	for enemy in enemies:
		if enemy.is_active() and enemy.overlaps_body(player):
			damage_player()
			return

func damage_player() -> void:
	if finished or player.invulnerable > 0.0:
		return
	lives -= 1
	player.invulnerable = 1.0
	print("生命：%d / %d" % [lives, MAX_LIVES])
	if lives <= 0:
		end_game(false)

func end_game(won_game: bool) -> void:
	finished = true
	won = won_game
	print(("你贏了！" if won_game else "失敗！") + "按 R 重新開始")
	player.set_physics_process(false)
	$SpawnTimer.stop()
	for enemy in enemies:
		enemy.set_physics_process(false)

func spawn_hazard() -> void:
	if finished or enemies.size() >= MAX_ENEMIES:
		$SpawnTimer.stop()
		return
	var enemy = ENEMY_SCENE.instantiate()  # 回傳型別是 Node，這裡刻意不標型別
	enemy.position = Vector2(60, 110)
	enemy.target = player
	enemy.add_to_group("enemies")
	add_child(enemy)
	enemies.append(enemy)
```

記得在 `enemy.tscn` 的節點面板把根節點加入 `enemies` 群組，`_ready()` 才找得到場景中原本的敵人。

現在有「贏」和「輸」兩種結束方式，把它們集中到 `end_game(won_game)`：把第 8 章 `collect_item()` 結尾的三行（`finished = true`、`print(...)`、`player.set_physics_process(false)`）改成一行 `end_game(true)`。以後結束時要多做什麼（停止敵人、顯示結果），只需要改這個函式；第 10 章就會從這裡接著重構。

### 步驟 5：早期 Web 匯出

1. 確認第 1 章已安裝與編輯器同版本的匯出範本。
2. 選單「專案 → 匯出」（Project → Export），按「新增」選 **Web**。
3. 把 `Export Path` 設為 `build/web/index.html`（先在專案中建立 `build/web` 資料夾，並確認 `.gitignore` 已忽略 `build/`）。
4. 檢查 `Thread Support`（執行緒支援）選項：本課程建議**關閉**，這樣產生的檔案不需要特殊伺服器標頭就能在一般靜態網站上執行。
5. 按「匯出專案」，在存檔對話框中保持「以除錯模式匯出」勾選（除錯版的錯誤訊息較完整，適合早期測試），按存檔。
6. 在終端機啟動本機伺服器並開瀏覽器：

```bash
cd ~/godot-projects/star-garden
python3 -m http.server 8000 --directory build/web
# 用瀏覽器開 http://localhost:8000
```

不要直接用瀏覽器開啟 `index.html` 檔案，`file://` 協定下 Godot 的 Web 版無法載入。在 WSL 中啟動的伺服器，通常可以直接從 Windows 的瀏覽器用 `localhost` 連線。

## 程式碼解說

- `enum Kind { CHASER, BOUNCER }`：列舉其實是有名字的整數（0 和 1）。用名字比較 `kind == Kind.CHASER`，程式讀起來就像規則本身。
- `is_instance_valid(target)`：目標可能已被刪除（例如重開時），先檢查再使用，避免錯誤。
- `drift.x = -drift.x`：撞到左右邊界就把水平速度反向，上下邊界同理；最後 `clamp` 把位置拉回範圍內，避免卡在邊界外來回抖動。
- `warmup`：敵人剛出現時倒數 0.5 秒，期間只畫一個閃爍的圓圈、不移動、不傷人。`is_active()` 把這個規則包成一個問題，主場景只要問就好。
- `enemy.overlaps_body(player)`：回傳這個 `Area2D` 目前是否和玩家重疊。它讀的是上一個物理步驟的結果，所以要在 `_physics_process` 中呼叫。
- `if finished or player.invulnerable > 0.0: return`：扣命前先檢查。無敵時間內每格都會偵測到重疊，但不會重複扣命。
- `return`（在迴圈中）：一個影格最多扣一次命，就算同時碰到兩隻敵人也一樣。
- `$SpawnTimer.stop()`：敵人數到上限或遊戲結束，就停止計時器，不再浪費呼叫。

## 自我檢查

- [ ] 新出現的敵人先閃爍約半秒，期間碰到不會受傷。
- [ ] 追蹤刺球會追著玩家轉彎；反彈菱形碰到場地邊緣會反彈。
- [ ] 被碰到一次少一條命，角色閃爍約 1 秒；期間再碰不會扣命。
- [ ] 一直貼著敵人不動，無敵結束後會再少一條命。
- [ ] 衝刺可以穿過敵人而不受傷。
- [ ] 每 6 秒多一隻追蹤刺球，總數不超過 5 隻。
- [ ] 第 3 次受傷時顯示失敗並停止移動；按 R 可以重來。
- [ ] 瀏覽器中可以載入並遊玩目前版本，按鍵有反應。

## 練習

1. 讓每隻新生成的追蹤刺球比上一隻快 10%，觀察難度曲線的變化。
2. 修改生成位置：從場地四個角落中挑一個**離玩家最遠**的角落（提示：比較 `distance_to()`）。下載版的 `far_point()` 就是這樣做的。
3. 比較兩種受傷判斷：用 `body_entered` 訊號，與在 `_physics_process` 中每格檢查。故意站在敵人裡不動，記錄兩者的差別。

## 常見錯誤與限制

- **一次碰撞扣多次**：扣命前沒有檢查 `invulnerable`，或無敵時間在扣命**之後**才檢查。
- **站在敵人裡不會再受傷**：用了 `body_entered` 判斷傷害，見上方「訊號只在進入時觸發一次」。
- **追蹤刺球不動**：`target` 沒有設定。場景中原本的敵人要在 `_ready()` 中指定，程式生成的敵人要在 `add_child` 前指定。
- **`Invalid access to property 'invulnerable'`**：`player` 變數指到的不是掛著玩家腳本的節點。
- **Web 版一片黑或卡在載入**：最常見是用 `file://` 直接開檔、範本版本不符，或啟用了執行緒支援但伺服器沒送出必要標頭。
- **Web 版沒有聲音**：瀏覽器規定要在使用者點擊或按鍵後才能播放聲音，這是平台限制，第 11 章會處理。
- **匯出後的畫面和編輯器不一樣**：檢查專案是否從一開始就使用 Compatibility 繪圖器。

## 學習目標

1. 建立以 `Area2D` 為根節點的障礙物場景，並讓其中一種沿路徑來回移動。
2. 讓障礙物發出訊號，由主場景累計受傷次數；累計 3 次判定失敗。
3. 用 `Timer` 實作受傷後的短暫無敵，避免一次碰撞被扣好幾次。
4. 在專案還小時就完成第一次 Web 匯出並在瀏覽器中執行，提早發現問題。

本章對應 2D 範例的「03 hazards」階段，見 [下載頁](../../downloads/)。

## 核心概念

### 為什麼需要無敵時間

`body_entered` 在玩家**進入**區域時觸發一次。但若玩家離開後馬上又碰回去，或同時碰到兩個相鄰的障礙物，就會在不到一秒內被扣好幾次。常見解法是受傷後給玩家一小段無敵時間（例如 1 秒），期間忽略所有傷害，並讓角色閃爍提示。

### 誰記錄受傷次數

和星星一樣，障礙物只負責回報「我碰到玩家了」，**次數由主場景記錄**。無敵狀態則屬於玩家本身。所以流程是：

1. 障礙物發出 `hit_player` 訊號。
2. 主場景收到後先問玩家「你現在能受傷嗎？」。
3. 可以的話，次數加一並讓玩家進入無敵；次數到 3 就判定失敗。

### 為什麼這麼早就做 Web 匯出

Web 平台有一些桌面沒有的限制：只支援 Compatibility 繪圖器、音效要等使用者互動後才能播放、有些功能需要特殊的伺服器標頭。專案越大，越難找出是哪一個改動在 Web 上出問題。**趁現在只有幾個場景時先匯出一次**，之後每完成一個階段就再測一次。完整說明在 [第 13 章](../13-web-export/)。

## 動手操作

### 步驟 1：障礙物場景

1. 新增場景，根節點 `Area2D`，命名 `Hazard`，加入 `hazards` 群組。
2. 加入 `CollisionShape2D`（`RectangleShape2D`，大小 `32×32`）。
3. 加入 `Polygon2D` 或 `ColorRect`，顏色用紅色系，形狀和碰撞框對齊。
4. 附加腳本並存成 `hazard.tscn`：

```gdscript
# 示範概念：碰到玩家時發出訊號的障礙物
extends Area2D

signal hit_player

func _ready() -> void:
	body_entered.connect(_on_body_entered)

func _on_body_entered(body: Node2D) -> void:
	if body.is_in_group("player"):
		hit_player.emit()
```

### 步驟 2：讓障礙物移動

最簡單的移動方式是在障礙物腳本中加入來回擺動。新增 `@export` 變數，讓每個實例可以設定不同的移動距離：

```gdscript
# 示範概念：沿 X 軸來回移動（加在 hazard.gd 中）
@export var move_distance := 0.0   # 0 表示不移動
@export var move_speed := 1.5

var _start_position := Vector2.ZERO
var _time := 0.0

func _physics_process(delta: float) -> void:
	if move_distance == 0.0:
		return
	_time += delta
	position.x = _start_position.x + sin(_time * move_speed) * move_distance
```

並在 `_ready()` 中加上 `_start_position = position`。在主場景放置 3 到 5 個障礙物，其中幾個把 `move_distance` 設為 `120`。也可以改用 `AnimationPlayer` 或 `Path2D` 加 `PathFollow2D` 做出更複雜的路線。

### 步驟 3：玩家的無敵時間

在玩家場景中加入 `Timer` 子節點，命名 `InvincibleTimer`，`Wait Time` 設 `1.0`，勾選 `One Shot`。在 `player.gd` 加入：

```gdscript
# 示範概念：玩家的受傷與無敵狀態（加在 player.gd 中）
@onready var invincible_timer: Timer = $InvincibleTimer

func can_take_damage() -> bool:
	return invincible_timer.is_stopped()

func start_invincible() -> void:
	invincible_timer.start()

func _process(_delta: float) -> void:
	# 無敵期間閃爍
	if invincible_timer.is_stopped():
		modulate.a = 1.0
	else:
		modulate.a = 0.3 if int(invincible_timer.time_left * 10) % 2 == 0 else 1.0
```

### 步驟 4：主場景累計受傷

在 `main.gd` 中加入：

```gdscript
# 示範概念：主場景累計受傷次數（加在 main.gd 中）
const MAX_HITS := 3
var hits := 0

func _connect_hazards() -> void:
	for hazard in get_tree().get_nodes_in_group("hazards"):
		hazard.hit_player.connect(_on_hazard_hit_player)

func _on_hazard_hit_player() -> void:
	# 回傳型別是 Node，要呼叫玩家自訂的函式，這裡刻意不標型別
	var player = get_tree().get_first_node_in_group("player")
	if player == null or not player.can_take_damage():
		return
	hits += 1
	print("受傷：%d / %d" % [hits, MAX_HITS])
	if hits >= MAX_HITS:
		_lose()
	else:
		player.start_invincible()

func _lose() -> void:
	print("失敗！按 R 重新開始")
	var player := get_tree().get_first_node_in_group("player")
	if player:
		player.set_physics_process(false)
```

記得在 `_ready()` 中呼叫 `_connect_hazards()`。

### 步驟 5：早期 Web 匯出

1. 確認第 1 章已安裝與編輯器同版本的匯出範本。
2. 選單「專案 → 匯出」（Project → Export），按「新增」選 **Web**。
3. 把 `Export Path` 設為 `build/web/index.html`（先在專案中建立 `build/web` 資料夾，並確認 `.gitignore` 已忽略 `build/`）。
4. 檢查 `Thread Support`（執行緒支援）選項：本課程建議**關閉**，這樣產生的檔案不需要特殊伺服器標頭就能在一般靜態網站上執行。（此選項在 Godot 4.3 之後提供，若你的版本介面不同，請以第 13 章與官方文件為準。）
5. 按「匯出專案」，在存檔對話框中保持「以除錯模式匯出」勾選（除錯版的錯誤訊息較完整，適合早期測試），按存檔。
6. 在終端機啟動本機伺服器並開瀏覽器：

```bash
cd ~/godot-projects/star-collector
python3 -m http.server 8000 --directory build/web
# 用瀏覽器開 http://localhost:8000
```

不要直接用瀏覽器開啟 `index.html` 檔案，`file://` 協定下 Godot 的 Web 版無法載入。在 WSL 中啟動的伺服器，通常可以直接從 Windows 的瀏覽器用 `localhost` 連線。

## 程式碼解說

- `get_tree().get_first_node_in_group("player")`：取得群組中的第一個節點，找不到時回傳 `null`，所以後面要檢查。
- `player.can_take_damage()`：把「能不能受傷」的判斷留在玩家身上，主場景不需要知道無敵是用 `Timer` 實作的。
- `invincible_timer.is_stopped()`：`One Shot` 的計時器跑完後會停止，代表無敵結束。
- `modulate.a`：節點的整體透明度（含子節點），用來做閃爍。
- `sin(_time * move_speed) * move_distance`：`sin` 的值在 -1 到 1 之間，乘上距離就得到來回擺動的位移。

**一個值得注意的細節**：如果玩家在無敵期間一直待在障礙物裡，無敵結束時並不會再次觸發 `body_entered`（因為沒有「重新進入」）。若你希望「持續待在障礙物中會持續受傷」，可以在無敵結束時用障礙物的 `get_overlapping_bodies()` 再檢查一次。這是一個很好的練習題，也是設計選擇，沒有唯一正解。

## 自我檢查

- [ ] 碰到障礙物一次，受傷次數只加一，角色開始閃爍約 1 秒。
- [ ] 無敵期間碰到障礙物不會加次數。
- [ ] 累計第 3 次時顯示失敗並停止移動；按 R 可以重來。

## 練習

1. 實作「無敵結束時若仍在障礙物中就再受傷一次」的行為，並比較兩種設計的遊戲體驗。
2. 把移動障礙物改用 `Path2D` 加 `PathFollow2D`，讓它沿著矩形路線巡邏。
3. 讓玩家受傷時被往反方向推開一小段距離（提示：把障礙物位置傳給玩家，計算方向後設定一次性的速度）。

## 常見錯誤與限制

- **一次碰撞扣多次**：沒有無敵時間，或多個障礙物重疊。先確認無敵判斷有在扣次數**之前**執行。
- **`Invalid call. Nonexistent function 'can_take_damage'`**：玩家腳本沒有這個函式，或群組裡的第一個節點不是玩家。
- **Web 版一片黑或卡在載入**：最常見是用 `file://` 直接開檔、範本版本不符，或啟用了執行緒支援但伺服器沒送出必要標頭。
- **Web 版沒有聲音**：瀏覽器規定要在使用者點擊或按鍵後才能播放聲音，這是平台限制，第 11 章會處理。
- **匯出後的畫面和編輯器不一樣**：檢查專案是否從一開始就使用 Compatibility 繪圖器。

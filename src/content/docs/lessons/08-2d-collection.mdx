## 學習目標

1. 建立以 `Area2D` 為根節點的星星場景，用 `_draw()` 以程式畫出五角星，不需要任何圖片。
2. 由主場景連接每顆星星的 `body_entered` 訊號，統一計數；收滿 10 顆時判定獲勝。
3. 用 `Tween` 讓被收集的星星放大並淡出，再自行刪除。
4. 用一次性的 `CPUParticles2D` 在收集位置噴出光點。
5. 理解碰撞層（Layer）與遮罩（Mask）如何決定誰偵測得到誰。

這個階段的 10 顆星星一次全部出現；第 10 章會把它們分成三波（3、3、4 顆）。本章對應 2D 範例的「02 collect」階段，可在 [下載頁](../../downloads/) 取得完整專案對照。

## 核心概念

### Area2D：偵測而不阻擋

`Area2D` 不會擋住任何東西，它只負責回報「有物體進來了」或「離開了」。星星、陷阱、終點、觸發區都適合用它。它的常用訊號是 `body_entered(body)`，當 `PhysicsBody2D`（例如玩家的 `CharacterBody2D`）進入時發出。

### 誰負責計數，誰負責動畫

沿用第 4 章的原則，把責任分開：

- **星星**只管自己的外觀：平常輕輕擺動，被收集時播放「彈開淡出」動畫，然後刪除自己。它不知道分數在哪裡。
- **主場景**連接每顆星星的 `body_entered`，確認進來的是玩家後，加分、要求星星播放動畫、在原地噴出粒子，並判斷是否獲勝。

### 用 `_draw()` 畫圖

每個 `CanvasItem`（所有 2D 節點與介面節點）都可以覆寫 `_draw()`，在裡面呼叫 `draw_circle()`、`draw_colored_polygon()` 等函式畫出外觀。`_draw()` 只在需要時執行；畫面要改變時呼叫 `queue_redraw()`，下一個影格就會重畫。五角星是 10 個頂點，外圈與內圈半徑交錯，用迴圈算出來最省事。

### Tween：用一行描述「在多少秒內變成什麼」

`create_tween()` 建立一個補間動畫，`tween_property(物件, "屬性", 目標值, 秒數)` 會在指定時間內把屬性平滑地改到目標值。預設依序播放，加上 `.parallel()` 則和前一段同時播放；`tween_callback()` 在動畫結束後呼叫函式。這比自己在 `_process` 裡寫計時器簡單許多。

### 碰撞層與遮罩

每個物理物件有兩組勾選框：

- **Layer（層）**：「我在哪些層上」。
- **Mask（遮罩）**：「我要偵測哪些層」。

星星要偵測玩家，所以星星的 Mask 必須勾選玩家所在的 Layer。預設大家都在第 1 層、也都偵測第 1 層，一開始不設定也能動。下載版把星星的 Layer 全部取消（`collision_layer = 0`）、Mask 只留第 1 層，意思是「我只偵測玩家，別人也不必偵測我」。

## 動手操作

### 步驟 1：建立星星場景與畫圖腳本

1. 新增場景，根節點選 `Area2D`，命名 `Star`。
2. 加入 `CollisionShape2D`，形狀選 `CircleShape2D`，半徑 `18`。
3. 在檢查器的 `Collision` 區塊，把 `Layer` 全部取消勾選，`Mask` 只勾第 1 層。
4. 附加腳本 `res://scripts/star.gd`，場景存成 `star.tscn`：

```gdscript
# 示範概念：會擺動、會彈開消失的星星
extends Area2D

const GOLD := Color("f6c453")
const LIGHT := Color("fff0b3")

var elapsed: float = 0.0
var taken: bool = false

func _process(delta: float) -> void:
	elapsed += delta
	if not taken:
		rotation = sin(elapsed * 2.0) * 0.15
	queue_redraw()

func star_points(outer: float, inner: float) -> PackedVector2Array:
	var points := PackedVector2Array()
	for i in 10:
		var radius := outer if i % 2 == 0 else inner
		var angle := -PI / 2.0 + i * PI / 5.0
		points.append(Vector2.from_angle(angle) * radius)
	return points

func _draw() -> void:
	draw_circle(Vector2.ZERO, 30.0, Color(GOLD, 0.12))
	draw_colored_polygon(star_points(21.0, 9.5), GOLD)

func pop() -> void:
	taken = true
	set_deferred("monitoring", false)
	var tween := create_tween()
	tween.tween_property(self, "scale", Vector2(1.8, 1.8), 0.18)
	tween.parallel().tween_property(self, "modulate:a", 0.0, 0.18)
	tween.tween_callback(queue_free)
```

開啟 `star.tscn` 按 F6，應該看到一顆在原地左右輕擺的金色星星，外圍有淡淡的光暈。

### 步驟 2：在主場景放 10 顆星星

1. 打開 `main.tscn`，新增一個 `Node2D` 叫 `Stars`。
2. 從檔案系統把 `star.tscn` 拖進 `Stars` 底下，選取它按 `Ctrl+D` 複製到 10 顆。
3. 把星星分散在場地內，避免放在牆裡或玩家出生點上。

### 步驟 3：主場景連接訊號並計數

擴充第 7 章的 `main.gd`：

```gdscript
# 示範概念：主場景連接訊號、計數並判定獲勝
extends Node2D

const TARGET: int = 10

var score: int = 0
var finished: bool = false

@onready var player: CharacterBody2D = $Player

func _ready() -> void:
	for star in $Stars.get_children():
		star.body_entered.connect(_on_star_body_entered.bind(star))

func _on_star_body_entered(body: Node2D, star: Area2D) -> void:
	if body == player:
		collect_item(star)

func collect_item(star: Area2D) -> void:
	if finished or star.taken:
		return
	star.pop()
	spawn_burst(star.position, star.GOLD)
	score += 1
	print("星星：%d / %d" % [score, TARGET])
	if score >= TARGET:
		finished = true
		print("你贏了！按 R 重新開始")
		player.set_physics_process(false)

func _unhandled_input(event: InputEvent) -> void:
	if event.is_action_pressed("restart"):
		get_tree().reload_current_scene()
```

`spawn_burst` 在下一步完成。若要先測試，可以暫時把那一行註解掉。

### 步驟 4：收集時噴出粒子

在 `main.gd` 加入兩個函式，並在 `_ready()` 開頭先建立一次貼圖：`dot_texture = soft_dot()`（`dot_texture` 是新增的成員變數 `var dot_texture: GradientTexture2D`）。

```gdscript
# 示範概念：一次性的圓點粒子爆散
func soft_dot() -> GradientTexture2D:
	var dot := GradientTexture2D.new()
	dot.width = 16
	dot.height = 16
	dot.fill = GradientTexture2D.FILL_RADIAL
	dot.fill_from = Vector2(0.5, 0.5)
	dot.fill_to = Vector2(1.0, 0.5)
	dot.gradient = Gradient.new()
	dot.gradient.set_color(0, Color.WHITE)
	dot.gradient.set_color(1, Color(1, 1, 1, 0))
	return dot

func spawn_burst(point: Vector2, color: Color) -> void:
	var burst := CPUParticles2D.new()
	burst.texture = dot_texture
	burst.position = point
	burst.one_shot = true
	burst.explosiveness = 1.0
	burst.amount = 18
	burst.lifetime = 0.45
	burst.spread = 180.0
	burst.gravity = Vector2.ZERO
	burst.initial_velocity_min = 90.0
	burst.initial_velocity_max = 240.0
	burst.color = color
	burst.finished.connect(burst.queue_free)
	add_child(burst)
	burst.emitting = true
```

執行遊戲，碰到星星時星星會放大淡出，同時噴出一圈金色光點；收滿 10 顆後角色停止移動。

你也可以在編輯器中加一個 `CPUParticles2D` 節點，直接在檢查器調整這些屬性並即時預覽，找到喜歡的數值後再寫進程式。

## 程式碼解說

- `star_points()`：`i` 從 0 到 9，偶數用外圈半徑、奇數用內圈半徑。每個點相差 `PI / 5`（36 度），起點 `-PI / 2` 讓尖角朝上。`Vector2.from_angle(角度)` 回傳該方向、長度為 1 的向量。
- `rotation = sin(elapsed * 2.0) * 0.15`：`sin` 在 -1 到 1 之間來回，乘上 0.15 弧度（約 8.6 度），星星就會輕輕左右擺。
- `set_deferred("monitoring", false)`：在碰撞回呼裡不能直接改物理狀態，要用 `set_deferred` 延到這個物理步驟之後。關閉 `monitoring` 後，星星在播動畫的期間不會再觸發。
- `tween.tween_property(self, "modulate:a", 0.0, 0.18)`：`modulate:a` 是「整體顏色的透明度」，冒號用來指定屬性中的一個分量。
- `tween.tween_callback(queue_free)`：前面兩段動畫結束後刪除星星。`queue_free` 會在影格結束才真正刪除，比較安全。
- `_on_star_body_entered.bind(star)`：`bind` 在訊號原本的參數（`body`）後面多附上一個參數，主場景就知道是哪一顆星星被碰到。
- `if finished or star.taken: return`：防呆。遊戲結束後不再計分，同一顆星星也不會被算兩次。
- `explosiveness = 1.0`：所有粒子在同一瞬間發射，形成爆散；`one_shot = true` 表示只發射一輪，結束時發出 `finished` 訊號，我們用它刪除粒子節點。
- `GradientTexture2D` 的 `FILL_RADIAL`：做出中心白、邊緣透明的圓點貼圖。沒有貼圖時，粒子會畫成 1 像素的方塊。
- 為什麼貼圖只建一次：`GradientTexture2D` 會在影格結束時才真正產生像素。若每次爆散都新建一張，網頁版在頭幾格可能取樣到尚未產生的貼圖，出現雜色光點。在 `_ready()` 建好、之後重複使用，既避免這個問題，也省下重複的工作。

## 練習

1. 讓星星除了擺動，也上下浮動（提示：在 `_draw()` 裡把所有座標加上 `Vector2(0, sin(elapsed * 3.0) * 4.0)`）。
2. 把粒子的 `gravity` 改成 `Vector2(0, 400)`，讓光點像碎片一樣往下掉，比較兩種感覺。
3. 把碰撞層命名為 player、pickups（專案設定 → 圖層名稱 → 2D 物理），重新設定玩家與星星的 Layer／Mask，確認遊戲行為不變。

## 常見錯誤與限制

- **碰到星星沒反應**：確認星星的 `Monitoring` 是開啟的、星星的 Mask 包含玩家的 Layer，以及訊號確實有連接（可以在 `_on_star_body_entered` 第一行加 `print` 檢查）。
- **計數超過 10**：同一顆星星在動畫期間又被觸發。檢查 `pop()` 有沒有關閉 `monitoring`，以及 `collect_item` 的 `star.taken` 判斷。
- **`Function blocked during in/out signal` 之類的錯誤**：在碰撞回呼中直接修改了 `monitoring` 或碰撞形狀，請改用 `set_deferred`。
- **星星不見了但沒畫面**：`_draw()` 中的座標以節點原點為中心，若你把形狀畫在 `(0, 0)` 到 `(40, 40)`，碰撞圓會和外觀錯開。
- **粒子是小方塊**：沒有設定 `texture`，或貼圖太小。
- **重開後計數沒歸零**：若把計數放在 Autoload（全域單例）中，`reload_current_scene()` 不會重設它。本章把計數放在主場景，重開時會自然歸零。

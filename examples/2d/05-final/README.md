# Star Garden — 2D 05-final

Polish: background shader, fireflies, dash afterimages, screen shake, sound effects and a saved best time.

Open `project.godot` in Godot 4.7.2 and press F5. WASD / arrow keys / left stick: move. Shift or Space / gamepad B: dash. Enter / Start: begin. R / gamepad Back: restart.

All graphics are drawn in code; sound effects are generated by the course build script (CC0). Code: MIT.

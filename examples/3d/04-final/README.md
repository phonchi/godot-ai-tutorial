# Floating Isles — 3D 04-final

Rolling patrol enemies on Path3D, respawn flags, title screen, timer, sound effects and a saved best time.

Open `project.godot` in Godot 4.7.2 and press F5. WASD / arrow keys / left stick: move. Space / gamepad A: jump. Enter / Start: begin. R / gamepad Back: restart.

All graphics are drawn in code; sound effects are generated by the course build script (CC0). Code: MIT.
